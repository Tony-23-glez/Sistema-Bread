# Sistema-Bread

## 📌 Descripción del proyecto

**Sistema-Bread** es una aplicación web desarrollada con **Next.js** que sirve como base para un sistema moderno orientado a la gestión y visualización de información. El proyecto utiliza tecnologías actuales del ecosistema JavaScript y está estructurado siguiendo las mejores prácticas de Next.js con el **App Router**.

Este proyecto está pensado como una base escalable, mantenible y lista para despliegue en entornos modernos como **Vercel**.

---

## 🚀 Tecnologías utilizadas

* **Next.js 13+** (App Router)
* **React**
* **TypeScript**
* **Node.js**
* **npm**
* **CSS global**
* **PostCSS**
* **ESLint**

---

## ⚠️ Notas importantes

* Durante el modo desarrollo puede aparecer un *warning* de **hydration mismatch** debido a extensiones del navegador. Esto **no afecta el funcionamiento ni el despliegue en producción**.
* El proyecto está preparado para desplegarse fácilmente en **Vercel**.
